Project Overview

Path of Ascension

Path of Ascension is a Xianxia-inspired Quest Explorer website developed for CSC 4370 Web Programming. The project allows users to explore a fictional cultivation world, discover different regions, view available missions, and interact with mission progress controls.

The website was developed using HTML5 and CSS3, focusing on responsive layouts, accessibility, and CSS-based interactions without JavaScript.
